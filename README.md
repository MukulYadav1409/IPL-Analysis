# 🏏 IPL Data Analysis (2008–2024)

## 📌 Project Overview

This project analyzes 17 seasons of the Indian Premier League (IPL) from 2008 to 2024 using SQL, Excel, Python, and Power BI.

The goal was to uncover patterns in team performance, player contributions, venue impact, toss decisions, and match outcomes while building an end-to-end data analytics workflow from data cleaning to dashboard creation.

This project demonstrates skills in data cleaning, exploratory data analysis (EDA), SQL querying, data visualization, and business storytelling.

## ❓ Business Questions Answered

### 📊 Team Performance

1. Which teams have won the most matches?
2. Which teams have the highest win percentage?
3. How has team performance evolved over different seasons?

### 🎯 Toss Analysis

4. Does winning the toss increase the chances of winning the match?
5. Which toss decision (bat/field) leads to better outcomes?

### 🏏 Player Analysis

6. Who are the highest run scorers in IPL history?
7. Which bowlers have taken the most wickets?
8. Which players have won the most Player of the Match awards?

### 🏟️ Venue Analysis

9. Which venues host the most IPL matches?
10. Which stadiums produce the highest-scoring games?

### 📈 Season Trends

11. How has scoring changed over IPL seasons?
12. Which season recorded the highest average first-innings score?
